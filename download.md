# Download the app

This is where you will go to get a very early version of Atlantis to look at, try out, and it will help people participate in discussions. 

### Big caveat

Don't download it yet, we're trying to do this quickly and will have the testing releases here, but even that isn't ready yet as of 10/1/26 by DW -- still diggin. ;-)

### Requirements

The app is only available for the Mac at this time. It runs in Electron, so it will be possible to create versions for any OS that supports Electron. 

The app is not signed with Apple. A copy that came through a browser will be refused by macOS the first time it's opened. 

It's built for Intel. On an Apple-chip Mac it runs through Rosetta, which macOS offers to install the first time.

### Download

To download click <a href="https://download.hellofrontier.com/electricFrontier.zip">this link</a>

After the software has loaded, expand the zip file and move the app file, electricFrontier.zip, where ever you want to put it. 

It will create a user folder in Library/Application Support/Electric Frontier. If you've used Frontier, this is the equivalent of the folder it installs, except the Frontier app doesn't live there. 

The download is 416MB in the first release

### Notes

Installing a new version over the old one keeps the user's database. The app never replaces it, so this part of your picture holds.
